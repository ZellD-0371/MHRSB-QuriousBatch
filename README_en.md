# Qurious Batch

**A PC mod for Monster Hunter Rise: Sunbreak that performs 10 armor Qurious Crafting rolls and lets you compare all results on one screen before choosing one.**

Select your armor and augmentation type at the smithy as usual to open the batch crafting screen. After spending the required materials, compare the 10 results and either apply one or keep your current augmentation.

## Features

- Supports regular, Stability, Skills+, and Slots+ armor augmentation
- Compare 10 results in a 5×2 card layout and inspect each result in detail
- Compare defense, resistances, decoration slots, and equipment skills
- Displays actual slot levels and distinguishes retained, added, and lost skill levels
- View skill descriptions and effects at each level
- View the skills from your currently equipped gear
- Manual and automatic material selection, with excess-point refund information
- Keyboard, mouse, and controller support
- Korean and English UI, with Nintendo, Xbox, and PlayStation button prompts
- Automatic resolution scaling with an additional 80–120% scale setting
- Toggle the mod using a shortcut in town, with an on-screen notification

## Installation

### Requirements

- **Monster Hunter Rise: Sunbreak** for Windows on Steam
- Armor Qurious Crafting unlocked in the game
- [REFramework](https://www.nexusmods.com/monsterhunterrise/mods/26?tab=files)

To install REFramework, extract `dinput8.dll` from the ZIP archive into your Monster Hunter Rise installation folder. 

Press **Insert** to open its menu.

### Mod Files

Close the game, then copy the following files into your game installation folder:

```text
MonsterHunterRise/
└─ reframework/
   ├─ autorun/
   │  ├─ QuriousBatch.lua
   │  └─ QuriousBatch/
   │     └─ *.lua
   └─ fonts/
      └─ QuriousBatch_Malgun.ttf
```

### Toggle Shortcut

| Input Device | Shortcut |
|---|---|
| Nintendo | **ZR + Left Stick Click** |
| Xbox | **RT + Left Stick Click** |
| PlayStation | **R2 + L3** |
| Keyboard | **~ + PageDown** |

The shortcut only works in town. It is disabled during quests, in the training area, while loading, and while a batch crafting session is in progress. An on-screen notification indicates whether the mod is enabled or disabled. You can also toggle it using the checkbox in the REFramework settings.

## Logs and Bug Reports

All paths below are relative to your **game installation folder**.

| File | Contents |
|---|---|
| `reframework/data/QuriousBatch.log` | Mod activity, costs, result selections, and errors |
| `re2_framework_log.txt` | REFramework activity, Lua errors, and native errors |
| `reframework_crash.dmp` | Crash dump generated by REFramework, if available |
| `reframework/data/QuriousBatch_settings.json` | Language, controller prompt, and UI scale settings |

After a crash, copy the logs before restarting the game. An existing dump may belong to an earlier crash, so check its modification time.

When reporting an issue, please include:

- Mod version, game version, and REFramework version
- Selected armor and augmentation type
- Actions immediately before the issue occurred and the input device used
- A screenshot of the error
- The log files listed above and any dump generated at the time of the crash
